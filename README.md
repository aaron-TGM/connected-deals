# connected-deals

Images for Connected Cannabis Co.'s Alpine IQ emails, served by GitHub Pages at
`https://aaron-tgm.github.io/connected-deals/…`. The email builder lives in the private repo `aaron-TGM/cc-aiq-emails`.

- `logos/`: Connected logos (`connected-script-white.png` for dark headers, `connected-script-black.png` for light ones).
- `products/<brand>-<category>.jpg`: 360×360 white product tiles, made with `scripts/make-asset.py wall` from the product photos on Connected's Jane menu.

Past emails link to these files, so **add new files only**: never overwrite, rename or delete one. A better photo gets a new name (for example `stiiizy-flower-2.jpg`).
